# Research

Everything behind the design decisions, with sources, so anyone can check the reasoning instead of taking it
on faith. Checked on the dates given; platforms change, so treat anything undated as stale.

- [The problem](problem.md) — how the scam works on music and on books, with the reported cases.
- [What the platforms offer](platforms.md) — remediation routes, and what each one lets a tool read.
- [Identifiers](identifiers.md) — why ASIN is weak, what ISBN, ISRC, UPC and MBID are worth, and what
  MusicBrainz, Discogs and Open Library can be used for.
- [Trust models](../docs/trust.md) — how ad blockers handle list trust, and why identity needs more.

Corrections are welcome as pull requests. If a finding here is wrong, the design built on it is probably wrong
too, which is the point of writing it down.
